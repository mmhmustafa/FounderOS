PRISM

PRISM is optional. Atlas discovers, correlates, investigates and explains without it — every fact on every page comes from collected evidence. PRISM, when you enable it, only rephrases what Atlas already concluded. It never creates evidence, never overrides a conclusion, and never changes a device.

Provider

Three modes: PRISM disabled (the default), a customer-hosted model on your own network, or a cloud provider. Switching provider is a settings change — no part of Atlas is rebuilt or restarted.

{{ csrf_field() }}

Governance

Policy is part of the configuration, so it is auditable. With cloud providers disallowed, a cloud provider cannot be selected or used even if configured.

Privacy and redaction

Credentials, API keys, SNMP communities and private keys are always removed before anything is sent — for every provider, with no way to switch that off. The options below add identifying detail to what is removed.
